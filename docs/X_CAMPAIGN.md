# Good Spark X campaign

Prepared August 24, 2026. These drafts use the current product facts: 460 affirmations, 22 languages, Mac/iPhone/iPad support, no account requirement, and no personal-data collection.

## Posting plan

- Publish each language as a separate, self-contained post. Do not place all translations in one thread.
- Start with the English release post, then publish one or two localized posts per day when that audience is awake.
- Use the localized product name and landing page in every market.
- Attach a localized screenshot or a short silent product video. Do not reuse an English text-heavy screenshot for a non-English post. The site does not currently declare an explicit social-preview image, so do not rely on the link card alone.
- Add image alt text in the same language as the post.
- Have a native speaker review copy before using it in a paid or pinned campaign.
- The copy below is designed for the standard 280-character limit. URLs count as 23 characters on X, but recheck the composer after any edit.
- Skip hashtags in the first wave. If a market already responds well, test one locally natural hashtag in a later post.

## Optional video brief

Use a 10–15 second silent capture that moves through three recognizable surfaces:

1. An affirmation in the iPhone app.
2. The Lock Screen or Dynamic Island view.
3. The Mac menu-bar popover.

Keep text overlays out of the shared master so the same edit can be used across markets. If text is added, export a localized version for each post. End on the app icon and the local-language product name.

## Regenerating the images

Start the local site, then run the renderer in a second terminal:

```bash
npm run dev -- --hostname 127.0.0.1 --port 3000
npm run promo:generate
```

To render only selected assets, set comma-separated `PROMO_LOCALES` and `PROMO_VARIANTS` values. For example:

```bash
PROMO_LOCALES=ja,ar PROMO_VARIANTS=overview npm run promo:generate
```

## Measurement

Compare each post's link clicks and downstream App Store results, then give the best-performing languages a second post focused on one feature: Live Spark, privacy, tone packs, or gentle streaks. The site currently has no analytics, so exact locale attribution requires campaign-tagged links or another privacy-compatible measurement setup.
